# BENZI-APP

Aplicatie pentru gasirea benzinariilor din apropiere si compararea preturilor carburantilor.

## MVP

Backend-ul:

- primeste locatia utilizatorului
- cauta benzinarii din apropiere
- preia preturile carburantilor
- calculeaza distanta pana la fiecare statie
- sorteaza statiile dupa distanta
- returneaza rezultatele printr-un API REST

## Tehnologii

- Python
- FastAPI
- Pydantic
- Requests
- PretCarburant API
- Pytest
